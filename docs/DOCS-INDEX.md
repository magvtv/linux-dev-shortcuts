## 🎯 Common Scenarios

### "I just cloned/downloaded this repo"
→ Read: **[README.md](README.md)**
→ Then: Run `./quick-start.sh`

### "Installation failed"
→ Check: **[INSTALLATION-CHECKLIST.md](INSTALLATION-CHECKLIST.md)** troubleshooting
→ Then: **[SYSTEM-WIDE-INSTALL.md](SYSTEM-WIDE-INSTALL.md)** troubleshooting section

### "Scripts don't work from /projects"
→ You need system-wide installation
→ Read: **[SYSTEM-WIDE-INSTALL.md](SYSTEM-WIDE-INSTALL.md)**
→ Run: `sudo ./install-system-wide-enhanced.sh`

### "What scripts are available?"
→ Read: **[README.md](README.md)** - "Scripts Overview"

### "How do I uninstall?"
→ Run: `sudo ./uninstall-system-wide.sh`
→ Or read: **[SYSTEM-WIDE-INSTALL.md](SYSTEM-WIDE-INSTALL.md)** - "Uninstalling"

### "I want to add my own scripts"
→ Add .sh files to dev-shortcuts subdirectories
→ Re-run: `sudo ./install-system-wide-enhanced.sh`
