How it works:
  • Creates wrapper scripts in /usr/local/bin/
  • Wrappers point to actual scripts in dev-shortcuts/
  • Adds dev-shortcuts to PATH in .bashrc and .profile
  • Configures git integration automatically
  • Makes all scripts executable
  • Verifies installation success

Why it works everywhere:
  • /usr/local/bin is always in PATH (standard Linux)
  • Wrappers are partition-independent
  • PATH includes dev-shortcuts for direct access
  • Works in any directory, any partition

Safety features:
  • Creates backups before modifying configs
  • Non-destructive installation
  • Can be run multiple times safely
  • Clean uninstall available
